# 口喷素材沉淀规则

本文件只在 `$content-production-workflow` 已收到用户口喷，且需要沉淀可跨选题复用素材时读取。

## 一、何时沉淀

口喷和必要追问完成后，只沉淀能跨选题复用、且确实来自用户的内容。没有可复用内容时不创建素材卡。

可用类型：

- `[观点]`：用户明确表达的判断和立场。
- `[方法]`：用户实际使用的步骤、标准和框架。
- `[经历]`：用户真实遇到的事情和取舍。
- `[案例]`：有具体场景、动作和结果的真实案例。
- `[故事]`：有人物、过程和转折的真实经历。
- `[原话]`：值得保留的用户原句。
- `[数据]`：已确认来源和口径的真实数据。

## 二、路径适配

优先使用当前工作区已有的用户素材库或内容资产目录。标准内容模板可使用：

`08_素材知识库/素材卡/{日期}_{主题关键词}.md`

没有现成目录时，在当前工作区中选择语义清楚的 `用户素材/` 或 `内容资产/`；不得跨项目保存。使用自定义位置时，在本次内容项目的读取回执中记录真实路径。

不按观点、方法、经历等类型拆成多个文件夹。同一次口喷或同一主题只建一张素材卡，用类型标签区分。

## 三、素材卡结构

```markdown
# 主题名称

> 状态：待确认｜来源：口喷原稿路径｜标签：关键词

- `[Ayyyymmdd-两位序号][类型]` 精简、忠实的素材内容。

## 边界

- 只保留复用该素材时必须知道的时间、事实、公开范围或隐私边界。
```

素材卡以完整保留可复用语义为准，通常 500—800 个汉字已经足够，内容少时应更短。

如果项目已有素材索引，同步增加一行：

```markdown
| ID | 类型 | 内容摘要 | 素材卡 | 状态 | 标签 |
```

没有索引时可以在同一素材目录创建语义清楚的 `素材索引.md`，但不得为了形式创建空索引。

## 四、状态、去重与隐私

- 新素材默认状态为“待确认”。只有用户明确确认后才更新为“已确认”。
- ID 必须唯一且稳定。
- 同主题素材卡已存在时去重更新，不新建近义重复文件。
- 只精确读取素材索引和同主题素材卡，不扫描整个资产库。
- 用户明确表示不保存、仅限本篇或涉及不应长期保留的隐私时，不沉淀到跨选题素材库。
- 不替用户推断未说出的动机、观点或经历。

## 五、不沉淀

- AI 建议和外部作者观点。
- 未确认数字、事实和产品信息。
- 只服务当前段落的过渡语。
- 重复表达和没有展开的碎片。
- 用户明确要求不长期保存的内容。
- 为了填满类型而硬凑的金句、案例和方法。

不单独建立“金句”分类。确实值得保留的用户原句标为 `[原话]`。
