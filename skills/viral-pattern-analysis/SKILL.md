# 爆款规律证据分析

在当前工作区内执行，遵守工作区已有的代理说明和文件保护规则。完整读取 [规律分析合同](references/pattern-analysis-contract.md)。

## 先适配工作区

按优先级确定素材集和输出位置：

1. 使用用户明确给出的文件、目录、批次、平台、时间范围和输出目录。
2. 若项目有素材索引，按索引筛选本轮范围，并把同一内容的 Markdown、图片、转写和数据合并成一条独立素材。
3. 若没有索引，只在当前工作区中寻找语义清楚的“爆款素材”或“高表现素材”目录，不跨项目扫描。
4. 输出目录由用户指定；未指定时，标准内容模板使用 `03_爆款规律/`，其他项目使用已有规律目录或新建 `爆款规律/`。
5. 无法唯一确定素材范围、多个项目混在一起或素材集为空时停止并说明，不凭猜测选样本。

## 两阶段执行

### 阶段一：逐条建立证据底稿

1. 建立去重后的独立素材清单，记录来源路径、平台、作者、日期、内容形式、链接和真实互动数据。
2. 完整读取每条素材实际存在的标题、文字正文、转写、图片文字和评论。缺失写“未采集”；无法读取记录路径和原因。
3. 严格区分标题、封面、图文正文、文字开头、视频口播开头和画面动作。
4. 按原始顺序记录正文结构和结尾动作，不提前套用熟悉的写作公式。
5. 保存证据底稿并回读审计。任何素材没有明确处理结果时，不进入完成状态。

### 阶段二：只根据底稿归纳

1. 只使用阶段一底稿作为规律证据；必要时回到原文件复核，不混入模型记忆、常识或未列入本轮的案例。
2. 先按平台、内容形式和开头载体分组，再判断能否跨组归纳。
3. 至少两条独立素材、且至少两个独立作者出现同一元素组合或结构动作，才列为跨作者候选规律。
4. 同一作者重复出现但缺少跨作者证据的，列为“作者重复做法”。
5. 只出现一次或证据不完整的，列为“单条观察”，不包装成规律。
6. 把高表现样本中的重复特征写成“候选规律”，不得宣称它导致爆款或保证结果。

## 输出

在规律目录中创建或增量维护：

- 本轮证据底稿；优先沿用项目已有命名，否则使用 `{日期或批次}_规律证据底稿.md`。
- `标题规律.md`
- `开头规律.md`
- `正文结构规律.md`
- `_规律索引与使用说明.md`

引用来源只保留证明判断所需的短片段，不复制整篇内容。已有文件不得静默覆盖：增量更新要保留旧证据、旧结论、反例、最后验证日期和变更说明。

## 完成门禁

写入后回读并确认：

1. 底稿中的独立素材数量与本轮清单一致。
2. 每条素材的组成部分、缺失项和读取失败都有记录。
3. 每条候选规律至少有两条独立素材和两个独立作者支持。
4. 作者重复做法与跨作者规律没有混淆，单条观察没有计入候选规律。
5. 平台、内容形式和不同开头载体没有被直接混合统计。
6. 索引只引用三份规律文件中已经存在的结论。
7. 没有补造原文、数据、评论、经历或因果结论，也没有修改原始素材。

最终汇报素材范围、独立素材数、各平台和内容形式数量、证据完整度、三类规律数量、无法读取项、待人工确认项和实际写入文件。
